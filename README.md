# uuill — 자산·부채 관리

자산과 부채를 한곳에서 관리하는 개인 재무 PWA입니다. 가계부, 투자 리밸런싱, 부채 상환 시뮬레이션, 목표(버킷리스트) 관리를 하나의 앱에서 할 수 있습니다.

## 주요 기능

- **홈 / 요약**: 월별 현황, 이번 달 액션, 목표 달성률
- **가계부**: 카테고리별 지출 기록과 집계
- **자산**: 현금·예금, ISA, 청약, ETF, 직투 등 자산 정리와 배분 현황
- **투자**: 현금흐름 자동 배분과 리밸런싱
- **부채**: 부채 상세, 상환 전략·대환 분석, 36개월 상환 시뮬레이션
- **목표**: 비상금 목표, 버킷리스트 우선순위, 5년 시나리오

## 사용 방법

빌드 과정이 없는 정적 웹앱입니다. `index.html`을 브라우저로 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

모바일에서 "홈 화면에 추가"를 누르면 앱처럼 설치해서 쓸 수 있습니다(PWA, 오프라인 캐시 지원).

## 데이터 저장

모든 데이터는 브라우저 `localStorage`에만 저장되고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 기록도 함께 사라집니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (UI, 로직, 스타일) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 오프라인 캐시용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
